## Lombok Task

This is a simple Java project that shows how Lombok helps you write less code. The `CarWithLombok` class only has fields, and Lombok generates the rest when you compile the project.

## Contains

- Lombok library added to IntelliJ IDEA and the project
- `CarWithLombok` class with only fields (no manual methods or constructors)
- A main class that creates two objects and compares them using `equals()` and `hashCode()`
- Code that compiles thanks to Lombok and the appropriate annotations, and prints the results to the console
- `equals()` returns `true` and `hashCode()` returns the same value, even though the two objects are different
